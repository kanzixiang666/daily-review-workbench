## 踩坑记录（资料库数据页 lint）
- DSDK002：HTML 内每个 `db.query/addRecord/updateRecord/deleteRecord/getSchema` 调用的 `databaseId` 必须是字符串字面量或名为 `DATABASE_ID` 的常量，传普通变量（如 DB3_ID、函数参数 dbId）会被判 FAIL → 多表页面要为每张表写带字面量的专用查询函数。
- DSDK011：`data-sp-database-id` 的值必须以字面量形式出现在 HTML 源码中，否则判不一致 → 把每个表的 id 字面量写进 SDK 调用即可同时解决两条。
- lint_database_sdk_usage 只接受单份 schema：多表页面可把三张表的 properties 合并成一份 {id,title,properties} 再校验。
- token（connect_open_platform，skill_id=library）有效期 1800 秒，长任务中途可能过期，报 NETWORK_ERROR 时重新换票即可。
- automation_update 的 RRULE 校验器不认 `BYHOUR=8,15` 逗号列表（报"must be integer"），需写成 `BYHOUR=8;BYHOUR=15`。
